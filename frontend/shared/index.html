Architectural Evaluation Distinction: YOLOv11 vs U-Net

YOLOv11 Object Detection:
  • Evaluates 2D Bounding Box coordinates $(x, y, w, h)$ & class classification.
  • IoU computes Intersection Area / Union Area of predicted bounding boxes.
  • Calculates mAP@50 and mAP@50-95 across confidence thresholds.
U-Net Semantic Segmentation:
  • Evaluates dense pixel-wise binary segmentation masks $\hat{M} \in \{0, 1\}^{H \times W}$.
  • Pixel IoU measures exact pixel mask overlap: $TP / (TP + FP + FN)$.
  • Calculates Dice Coefficient: $2TP / (2TP + FP + FN)$.
  • Calculates Mask mAP@50 & mAP@50-95 for dense morphological contour overlap.
